# Play Console 데이터 보안·앱 콘텐츠 양식 답안 가이드

> 현재 코드(2026-11-16) 기준 답안 초안입니다. 기능을 바꾸면(광고·분석·서버 도입 등) 반드시 다시 확인하세요. 양식 문구는 Console에서 바뀔 수 있으니 화면의 현재 질문을 우선합니다.

## 데이터 보안(Data safety)
| 질문 | 권장 답 | 근거 |
|---|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | **수집 안 함 / 공유 안 함** | 자체 서버 없음, 분석·광고·크래시 SDK 없음. 모든 데이터는 기기 내부 저장 |
| 결제 정보는? | 운영자가 수집하지 않음 | Google Play 결제가 처리(개발자에게 전달되지 않음) |
| 전송 중 암호화 | 해당 없음(전송 데이터 없음) | |
| 데이터 삭제 요청 방법 | 해당 없음 — 앱 삭제/저장소 지우기로 모두 삭제 | |
| 알림·클립보드 | 수집 아님 | 알림은 로컬, 클립보드는 "붙여넣기" 버튼을 누를 때만 읽음 |

> 도전장 공유는 사용자가 고른 앱으로 사용자 본인이 보내는 것이라 개발자가 수집하는 데이터가 아닙니다.

## 광고 / 앱 액세스 / 타깃
- 광고 포함: **아니요**(1차 릴리스에 광고 없음)
- 앱 액세스 제한(로그인 필요): **아니요**
- 타깃 연령: 사용자 결정. 어린이(13세 미만)를 포함하면 Families 정책이 추가로 적용되니 일반 이용자 대상(13세 이상 또는 성인)을 권장
- 뉴스 앱 / 정부 앱 / 금융 기능 / 건강 기능: 모두 **아니요**

## 콘텐츠 등급(IARC) 설문 예상 답
폭력·성적 콘텐츠·욕설·도박·약물 **없음**, 사용자 간 상호작용 없음(도전장은 외부 앱으로 문구 전달뿐), 위치 공유 없음, 디지털 구매 있음(프리미엄). 퍼즐 카테고리.

## 선언해야 할 권한·항목
- 병합된 매니페스트의 실제 권한(릴리스 APK 확인): `POST_NOTIFICATIONS`(선택, 오늘의 도전 알림), `com.android.vending.BILLING`·`INTERNET`·`ACCESS_NETWORK_STATE`(결제 라이브러리), `RECEIVE_BOOT_COMPLETED`·`WAKE_LOCK`·`FOREGROUND_SERVICE`(WorkManager가 추가; 앱은 포그라운드 서비스를 직접 쓰지 않음 — Console이 포그라운드 서비스 선언을 요구하면 "사용하지 않음"으로 답하거나 매니페스트에서 제거 검토)
- 인앱 상품: `premium_lifetime`(일회성, 비소모성)
- 개인정보 처리방침 URL: `docs/PRIVACY_POLICY.md`를 웹에 게시한 주소
- 대상 API: targetSdk 36 ✓(2026-08-31부터 신규 앱 요건, 공식 문서 확인), 16KB 페이지 크기 호환 ✓(네이티브 라이브러리 정렬 점검 완료)
